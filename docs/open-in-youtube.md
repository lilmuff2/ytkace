# Открытие ссылок в YouTube

IPA включает два расширения, собранных из исходников в `Extensions/`:

- **Safari:** кнопка «Открыть в YouTube» на страницах youtube.com и youtu.be, а также пункт в меню расширений Safari. Поддерживает watch, Shorts, live, clip, каналы, плейлисты и метки времени. Кнопка на странице обновляет ссылку при переходах внутри YouTube.
- **Поделиться:** пункт «Открыть в YouTube» принимает ссылку или текст со ссылкой и передаёт её установленному приложению. При отказе iOS показывает сообщение с предложением открыть ссылку через Safari.

## Установка

1. Подпиши IPA в KSign с сохранением расширений (`PlugIns`). Подписывающий инструмент должен подписать каждое расширение с профилем, разрешающим его Bundle ID.
2. Открой YouTube один раз после установки.
3. В настройках iOS открой **Приложения → Safari → Расширения → Открыть в YouTube**, включи расширение и разреши доступ к youtube.com и youtu.be.
4. В меню «Поделиться» открой **Ещё** и включи «Открыть в YouTube», если оно скрыто.

Идентификаторы расширений формируются из идентификатора приложения:

```
com.google.ios.youtube.YTKACEOpenSafari
com.google.ios.youtube.YTKACEOpenShare
```

Расширения используют существующую схему `youtube://`. Если одновременно установлено другое приложение с этой схемой, выбор приложения делает iOS. Для сборки с оригинальным Bundle ID это тот же обработчик, который использует YouTube.

Safari требует нажатия кнопки и может показать системное подтверждение открытия приложения. Расширение не восстанавливает Universal Links в других приложениях.

Открытие приложения из Share Extension ограничено iOS: сначала используется `NSExtensionContext.openURL`, затем динамически доступный метод `UIApplication.openURL:options:completionHandler:`. Последний способ зависит от версии iOS и приложения, из которого вызвано меню. На устройстве нужно проверить как холодный запуск YouTube, так и уже запущенное приложение. App Groups и сервер не используются.

## Проверка

```
node Tests/test_extension_links.js
xcrun clang -fobjc-arc -framework Foundation Tests/extension_links.m Extensions/Share/Link.m -o /tmp/ytkace-link-tests
/tmp/ytkace-link-tests Tests/link_cases.json
```

Оба обработчика проверяются одним набором ссылок: короткие ссылки, временные метки, разные пути, поддельные домены и запрещённые схемы. `Tools/verify-artifacts.sh` проверяет расширения внутри итогового IPA. Сборка расширений требует Xcode и выполняется автоматически при упаковке IPA.
